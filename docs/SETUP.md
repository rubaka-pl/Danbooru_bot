# 🚀 Как запустить бота — пошаговая шпаргалка

Иди по пунктам сверху вниз и ставь галочки. Всё, что помечено **(один раз)**, делается только при первой настройке.

---

## Шаг 1. Telegram (один раз)

- [ ] **Токен бота.** В [@BotFather](https://t.me/BotFather): `/mybots` → выбери бота → *API Token*. Это `BOT_TOKEN`. Никому его не показывай.
- [ ] **Включить inline-режим** (чтобы работало `@бот miku` в любом чате).
      @BotFather → `/setinline` → выбери бота → напиши подсказку, например `miku, rem, frieren…`
- [ ] **Бот — админ канала.** Канал → Управление каналом → Администраторы → Добавить → найди бота → включи право **«Публикация сообщений»**.
- [ ] **Реакции в канале включены.** Канал → Управление каналом → Реакции → «Все реакции» или выбранные. Без этого бот не сможет подстраиваться под вкусы и собирать «Топ недели».
- [ ] **Твой Telegram ID** (для админки `/admin`, `/post`, `/pause`). Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт число. Это `ADMIN_IDS`.

## Шаг 2. База данных Upstash Redis (один раз, бесплатно)

Нужна, чтобы избранное, подписки, настройки, статистика и история постов **не пропадали** при перезапуске. На бесплатном Render без неё всё стирается при каждом деплое.

- [ ] Зарегистрируйся на [upstash.com](https://upstash.com) → **Create Database** → тип Redis, регион поближе (например `eu-central-1`), план Free.
- [ ] Открой базу → вкладка **REST API** → скопируй:
  - `UPSTASH_REDIS_REST_URL` (вида `https://xxx.upstash.io`)
  - `UPSTASH_REDIS_REST_TOKEN`

> На Vercel можно проще: проект → Storage → Upstash Redis → Connect. Переменные подставятся сами.

## Шаг 3. Хостинг — выбери ОДИН вариант

### Вариант А: Render (проще, бот работает постоянно)

- [ ] [dashboard.render.com](https://dashboard.render.com) → **New → Web Service** → подключи репозиторий.
- [ ] Build Command: `npm install`
- [ ] Start Command: `npm start`
- [ ] **Environment** → добавь переменные (см. таблицу ниже): минимум `BOT_TOKEN`, `GROUP_ID`, `ADMIN_IDS`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`.
- [ ] Deploy. В логах должно появиться `🟢 Бот @... запущен`.
- [ ] Если раньше бот работал на Vercel — один раз выполни локально `BOT_TOKEN=... npm run webhook:delete` (иначе Telegram продолжит слать апдейты туда).

> Бесплатный Render «засыпает» без входящих запросов. Чтобы не засыпал, на [cron-job.org](https://cron-job.org) создай задачу, которая каждые 10 минут открывает адрес сервиса (`https://<имя>.onrender.com`).

### Вариант Б: Vercel (serverless, бот «спит», пока нет сообщений)

- [ ] [vercel.com](https://vercel.com) → **Add New → Project** → импортируй репозиторий. Настройки сборки не трогай.
- [ ] Storage → **Upstash Redis** → Connect (или вручную добавь переменные из шага 2).
- [ ] Settings → **Environment Variables**: `BOT_TOKEN`, `GROUP_ID`, `ADMIN_IDS`, `WEBHOOK_SECRET` (придумай длинную случайную строку), `CRON_SECRET` (ещё одна строка). Затем **Redeploy**.
- [ ] Установи webhook — **один раз, у себя на компьютере** в папке проекта:
  ```bash
  npm install
  BOT_TOKEN=... WEBHOOK_URL=https://<проект>.vercel.app/api/webhook WEBHOOK_SECRET=... npm run webhook:set
  ```
  В конце должно напечататься `✅ Webhook установлен`.
- [ ] На [cron-job.org](https://cron-job.org) (бесплатно) создай **две** задачи:

  | Что | URL | Как часто |
  |---|---|---|
  | Автопост в канал | `https://<проект>.vercel.app/api/autopost?secret=<CRON_SECRET>` | каждые 5–10 минут |
  | Подписки + «Топ недели» | `https://<проект>.vercel.app/api/digest?secret=<CRON_SECRET>` | каждый час |

  Встроенный cron Vercel на бесплатном тарифе запускается только раз в день, поэтому нужен внешний.

> ⚠️ Одновременно работает только один вариант. Render и Vercel вместе — нельзя.

## Шаг 4. Проверка, что всё работает

- [ ] Напиши боту `/start` — пришла справка.
- [ ] Напиши `hatsune miku` → нажми «📥 3» → пришли 3 картинки с кнопками ❤️ 🔍 📥 🎨 👤.
- [ ] Напиши `hatsue miku` (с опечаткой) → бот предложит «💡 hatsune_miku».
- [ ] Пришли боту любую аниме-картинку → он найдёт источник.
- [ ] В любом чате набери `@имя_бота frieren` → появилась сетка картинок.
- [ ] `/quiz` → угадай персонажа.
- [ ] `/admin` → видна админка. Нажми «📤 Запостить сейчас» → пост появился в канале.
- [ ] `/settings` → попробуй «⚡ Быстрый режим».

## Переменные окружения

| Переменная | Нужна? | По умолчанию | Что это |
|---|---|---|---|
| `BOT_TOKEN` | **да** | — | токен от @BotFather |
| `GROUP_ID` | да | `@Obitel_Dionisa` | канал для автопоста |
| `ADMIN_IDS` | желательно | — | твой Telegram ID (несколько — через запятую) |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | желательно (на Vercel — **да**) | — | база данных |
| `WEBHOOK_SECRET` | только Vercel | — | защита webhook |
| `CRON_SECRET` | только Vercel | — | защита `/api/autopost` и `/api/digest` |
| `AUTOPOST` | нет | `on` | `off` — выключить автопост |
| `AUTOPOST_INTERVAL` | нет | `60` | секунд между автопостами (Render) |
| `QUIET_HOURS` | нет | `23:30-06:00` | тихие часы автопоста, `off` — без них |
| `TZ_NAME` | нет | `Europe/Warsaw` | часовой пояс (тихие часы, рассылки, топ недели) |
| `ALBUM_EVERY` | нет | `8` | ≈ каждый N-й автопост — альбом; `0` — без альбомов |
| `ADAPTIVE_SHARE` | нет | `0.4` | доля постов по «залайканным» тегам |
| `DIGEST_HOUR` | нет | `12` | час ежедневной рассылки подписок |
| `RECAP` | нет | `on` | `off` — не публиковать «Топ недели» |
| `RECAP_WEEKDAY`, `RECAP_HOUR` | нет | `0`, `20` | когда публиковать топ (0 — воскресенье) |
| `DANBOORU_LOGIN`, `DANBOORU_API_KEY` | нет | — | аккаунт Danbooru (больше тегов в запросе) |
| `DANBOORU_TAG_LIMIT` | нет | `2` | 6 для Gold, 12 для Platinum |

## Если что-то не работает

| Проблема | Что проверить |
|---|---|
| Бот молчит | Логи хостинга. На Vercel — что webhook установлен (`npm run webhook:set`) и `WEBHOOK_SECRET` совпадает. На Render — что webhook **удалён** (`npm run webhook:delete`). |
| Нет автопостов | Бот — админ канала? `GROUP_ID` правильный? Не тихие часы? Не на паузе (`/admin`)? На Vercel — работает ли задача cron-job.org (в ней видно ответ). |
| Inline не работает | `/setinline` в @BotFather. |
| `/stats` пустой, «Топ недели» не выходит | Реакции в канале включены? Бот — админ? Статистика копится с момента, когда бот начал постить с этой версией. |
| Пропадают избранное/подписки | Не подключён Redis (шаг 2). |
| «Danbooru просит подождать» | Слишком много запросов — подожди минуту. Можно указать аккаунт Danbooru. |
| `/admin` пишет «выключены» | Не задан `ADMIN_IDS`. |

## Для разработки

```bash
npm install
cp .env.example .env     # заполни BOT_TOKEN
node --env-file=.env src/index.js
npm test                 # все тесты
npm run test:coverage    # покрытие
```
